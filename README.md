# Lifecoon — mises à jour

Manifeste de mise à jour (`latest.json`) et binaires (APK dans les *Releases*) de l'application **Lifecoon** (suivi de santé personnel, par Bengacoon).

- **App** : suivi tension, glycémie, poids, traitements, ordonnances, appareils… 100 % local et chiffré.
- **Code source** : privé.
- **iOS** : sur l'App Store.

L'application vérifie ce dépôt pour proposer les mises à jour (aucune donnée personnelle envoyée).
